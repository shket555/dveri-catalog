# Каталог стальных дверей

Современный, чистый и быстрый мини-сайт каталога входных стальных дверей.
Все данные (348 моделей дверей, фотографии, характеристики, описания, цены) полностью скопированы и перенесены из исходной базы сайта.

## Как открыть сайт
Просто откройте файл `index.html` в любом современном браузере (двойной клик мыши) — сайт работает автономно, без необходимости установки веб-сервера.

Также его можно развернуть на любом веб-сервере (Nginx, Apache, GitHub Pages, Vercel и т.д.).

## Содержимое папки `catalog/`
- **`index.html`** — главная страница каталога с адаптивной версткой, боковой панелью фильтров, поисковой строкой и модальным окном детального просмотра.
- **`styles.css`** — современные стили, чистый дизайн без лишних элементов и баннеров, плавная анимация и полная адаптивность для ПК, планшетов и смартфонов.
- **`app.js`** — логика каталога (живая фильтрация, подсчёт моделей, поиск, сортировка, листание страниц, управление модальным окном и галереей фотографий).
- **`doors-data.js`** — база данных всех 348 дверей в формате JavaScript для мгновенной загрузки даже при открытии через локальный протокол `file://`.
- **`doors.json`** — та же база данных в формате чистого JSON для возможности интеграции с API или бэкендом.
- **`images/`** — папка со всеми 2 064 локальными фотографиями дверей (снаружи, внутри, крупный план, фото в интерьере).

## Возможности каталога
1. **Каталог товаров**:
   - Карточки с показом вида снаружи и изнутри двери.
   - Бейджи: «Новинка», «Акция», «Хит», «На заказ».
   - Краткие характеристики прямо на карточке (толщина полотна, короб, внутренняя отделка).
   - Точная цена в рублях (и перечеркнутая старая цена для акций).
2. **Фильтры (полностью соответствуют исходному сайту)**:
   - **По цене**: диапазоны (от 14 000 до 25 000 ₽, от 26 000 до 34 000 ₽, от 35 000 до 110 000 ₽, от 111 000 ₽) + поля для ввода точной минимальной и максимальной цены.
   - **По отделке**: С зеркалом, Панель / Панель, Металл / Панель, Металл / Металл, Белые двери.
   - **По конструкции**: 2-х контурные, 3-х контурные, С терморазрывом, С окном, Двустворчатые, С электронным замком, С адаптивной замковой частью.
   - **По назначению**: В квартиру, В частный дом, Тамбурные.
   - Динамический счетчик доступных моделей у каждого чекбокса.
   - Кнопка «Сбросить всё» и интерактивные теги (чипы) активных фильтров.
3. **Поиск и сортировка**:
   - Живой поиск по названию модели, замкам или отделке.
   - Сортировка: по популярности, сначала дешевле, сначала дороже, по названию (А-Я / Я-А).
4. **Модальное окно карточки двери**:
   - Открывается по клику на любую дверь.
   - Фотогалерея с переключением ракурсов (снаружи, внутри, интерьер).
   - Полная структурированная таблица всех характеристик (короб, полотно, петли, замки, фурнитура, утепление, вес, размеры и т.д.).
   - Вкладка с подробным описанием модели.
   - Листание следующей/предыдущей двери кнопками `←` / `→` или стрелками на клавиатуре.
   - Закрытие по клавише `ESC` или клику вне окна.
